## 개인 환율 기록

화면: `FX-01`

로그인 참여자는 여행별로 자신의 환전 환율을 기록할 수 있다.
개인 환율 기록은 환전 날짜, 환전 수단, 통화와 환율로 구성한다.
환전 수단은 현금과 트래블 카드 중 하나다.
개인 환율 기록의 통화는 JPY, USD, EUR, CNY다.
로그인 참여자는 0보다 크고 정수부 10자리, 소수점 둘째 자리까지인 환율만 입력할 수 있다.

환전 날짜는 회원이 선택한 환전 당시의 현지 날짜다.
서비스는 환전 시각, 현재 위치와 국가코드를 수집하지 않는다.
서비스는 환전 날짜를 UTC로 변환하지 않는다.
환전 날짜는 기록용이며, 서비스는 환전 날짜로 기존 지출에 적용할 기간을 정하지 않는다.

같은 여행방에서 본인이 통화, 일자, 수단과 환율이 모두 같은 기록을 다시 저장하면 서비스는 저장을 거절한다.
환율이 같아도 일자가 다르면 서비스는 별개 이력으로 저장한다.
서비스는 저장 환율을 등록자 본인에게만 보여 준다.

## 지출 환율

화면: `EXP-02`, `EXP-03`, `EXP-04`, `FX-01`

지출을 등록하는 관리자와 로그인 참여자, 수정 잠금을 획득한 기록자나 관리자는 지출마다 적용 환율을 바꿀 수 있다.
지출 권한은 [등록과 권한](expense.md#등록과-권한)을 따르며, 이 절의 회원은 이 권한을 가진 회원이다.
결제일의 API 환율을 기본값으로 제공하면 앱은 출처와 기준일을 함께 표시한다.

결제일에 고시 환율이 없으면 서비스는 결제일 이전 7일 안에 고시된 가장 최근 환율을 제공한다.
이전 고시 환율을 제공하면 앱은 실제 고시 기준일과 선택한 날짜의 고시값이 없어 이전 고시값을 썼다는 안내를 표시한다.
서비스는 미래 날짜의 환율 조회를 허용하지 않는다.
결제일과 그 이전 7일 안에 고시된 환율이 없으면 앱은 조회 불가를 안내한다.
조회 불가를 안내받으면 회원은 환율을 직접 입력할 수 있다.

다음 표는 신규 지출의 기본 환율이다.

| 신규 지출 조건 | 기본 환율 |
| --- | --- |
| 본인 결제, 현금 또는 트래블 카드 | 선택한 결제 통화에서 가장 최근에 등록한 개인 환율 |
| 일반 카드 결제 또는 타인 결제 | 결제일 기준 API 환율 |

서비스는 전체 1/N과 메뉴/품목별 분배에 같은 기본 환율 기준을 적용한다.

본인 현금이나 트래블 카드 지출에 필요한 저장 환율이 없으면 앱은 다음 단계로 넘어가지 않는다.
저장 환율이 없으면 앱은 환율 등록을 안내한다.
회원이 환율을 등록하는 동안 앱은 입력 중인 지출 정보를 유지한다.
회원이 등록을 완료하면 앱은 등록한 환율을 그 지출에 바로 적용한다.
회원은 결제 수단을 카드로 바꿔 API 환율을 쓸 수 있다.

서비스는 선택한 결제 통화의 저장 환율 중 최초 등록 시각이 가장 늦은 기록을 쓴다.
회원이 기존 저장 환율을 수정해도 최근 순서는 바뀌지 않는다.
회원이 결제 통화를 바꾸면 서비스는 새 결제 통화에 맞는 환율을 다시 적용한다.

회원이 환율을 직접 수정하면 서비스는 수정한 환율을 그 지출에 적용한다.
본인 현금이나 트래블 카드 지출에서 회원이 환율을 직접 수정하면 서비스는 그 환율을 개인 환율 기록에도 자동 저장한다.
회원이 다음 지출을 등록하면 앱은 직전에 입력한 환율을 자동으로 보여 준다.
서비스는 직전 입력 환율을 여행방별, 결제 통화별로 관리한다.
1차 MVP에서 서비스는 직접 수정한 환율의 자동 저장과 직전 입력 환율의 표시를 제공한다.

API 환율 조회가 실패하면 회원은 지출에 적용할 환율을 직접 입력할 수 있다.
서비스는 API에서 조회한 환율을 개인 환전 기록으로 자동 등록하지 않는다.

## 저장된 지출과 정산

화면: `FX-01`, `EXP-05`, `SETTLE-02`

지출을 저장하면 서비스는 적용한 환율, 출처와 기준일을 함께 보존한다.
개인 환율을 등록하거나 변경해도 서비스는 기존 지출의 환율과 부담액을 자동으로 바꾸지 않는다.

회원이 지출을 수정하면 앱은 그 지출에 저장된 환율을 표시한다.
적용 환율의 변경은 지출 수정 권한과 [수정과 잠금](expense.md#수정과-잠금)의 조건을 따른다.

서비스는 정산에 각 지출에 저장된 환율을 쓴다.
서비스는 정산에 실시간 환율이나 새 환율을 적용하지 않는다.
원화 통합과 통화별 정산의 차이는 [정산 방식](settlement.md#정산-방식)을 따른다.
