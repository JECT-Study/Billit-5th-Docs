## 개인 환율 기록

화면: `FX-01`

로그인 참여자는 여행별로 자신의 환전 환율을 기록한다. 환전 날짜, 환전 수단, 통화와 환율을 입력하며, 환전 수단은 현금과 트래블 카드로 구분한다.

지원 통화는 KRW, JPY, USD, EUR, CNY다. 환율은 0보다 커야 하며 소수점 둘째 자리까지 입력한다. 환전 날짜는 기록용이며 기존 지출에 적용할 기간을 지정하지 않는다.

환전 날짜는 사용자가 선택한 환전 당시의 현지 날짜다. 시각은 수집하지 않으며 UTC로 변환하지 않는다. 현재 위치와 국가코드는 수집하지 않는다.

같은 여행방에서 본인의 동일 통화, 동일 일자, 동일 수단, 동일 환율 기록을 중복 저장할 수 없다. 환율이 같아도 일자가 다르면 별개 이력으로 관리한다. (회의 결정)

저장 환율은 등록자 본인만 조회한다. 다른 참여자의 저장 환율 목록은 제공하지 않는다.

> 논의 필요
>
> 저장 환율 수정과 삭제 제공 여부 및 사용 중인 환율 삭제 조건을 정해야 한다.

> 추후 검토
>
> 다른 참여자에게 개인 저장 환율을 공개하는 기능은 2차 범위에서 검토한다.

## 지출 환율

화면: `EXP-02`, `EXP-03`, `EXP-04`, `FX-01`

환율은 지출마다 지정하며 사용자가 변경할 수 있다. 결제일의 API 환율을 기본값으로 제공하는 경우 출처와 기준일을 함께 표시한다.

결제일에 고시 환율이 없으면 그 날짜 이전에 고시된 가장 최근 환율을 제공한다. 실제 고시 기준일을 표시하고, 선택한 날짜의 고시값이 없어 이전 고시값을 사용했다는 안내를 함께 제공한다. 미래 날짜의 환율 조회는 허용하지 않는다. 요청 날짜와 그 이전에 제공 가능한 고시 환율이 전혀 없으면 조회 불가로 안내하고 직접 입력할 수 있게 한다.

| 신규 지출 조건 | 기본 환율 |
| --- | --- |
| 본인 결제, 현금 또는 트래블 카드 | 선택한 결제 통화에서 가장 최근에 등록한 개인 환율 |
| 일반 카드 결제 또는 타인 결제 | 결제일 기준 API 환율 |

이 기준은 전체 1/N과 메뉴/품목별 분배에 공통으로 적용한다.

본인 현금 또는 트래블 카드 지출에서 필요한 저장 환율이 없으면 다음 단계 진행을 막고 환율 등록을 안내한다. 입력 중인 지출 정보는 유지하며, 등록을 완료하면 해당 지출에 바로 적용한다. 카드로 결제 수단을 바꿔 API 환율을 사용할 수도 있다.

저장 환율은 선택한 결제 통화와 같은 기록에서 최초 등록 시각이 가장 최근인 값을 사용한다. 기존 환율을 수정해도 최근 순서는 바뀌지 않는다. 결제 통화를 변경하면 해당 통화에 맞춰 적용할 환율도 갱신한다.

사용자가 직접 수정한 환율은 해당 지출에 적용한다. 본인 현금 또는 트래블 카드 지출에서 직접 수정한 환율은 개인 환율 기록에도 자동 저장한다. 다음 지출 등록 시 직전 입력 환율을 자동 노출하며 여행방별, 결제 통화별로 관리한다. 이 기능은 1차 MVP에 포함한다. (회의 결정)

API 조회가 실패하면 지출에 적용할 환율을 직접 입력할 수 있다. API에서 조회한 값 자체를 개인 환전 기록으로 자동 등록하지 않는다.

> 논의 필요
>
> 같은 통화의 기록을 고를 때 환전 수단도 같아야 하는지 결정한다.
>
> 수동 수정값의 자동 저장 시점과 일자 및 수단 매핑, 일반 카드 또는 타인 결제의 수동 입력값도 자동 저장할지와 저장 시 수단 표현, 기존 기본 환율 선택 규칙과 직전 입력값의 우선순위를 확정해야 한다.

## 저장된 지출과 정산

화면: `FX-01`, `EXP-05`, `SETTLE-02`

지출을 저장하면 적용한 환율, 출처와 기준일도 함께 보존한다. 개인 환율을 등록하거나 변경해도 기존 지출의 환율과 부담액을 자동 변경하지 않는다.

지출을 수정할 때는 해당 지출에 저장된 환율을 표시한다. 적용 환율 변경은 지출 수정 권한과 잠금 조건을 따른다.

정산은 각 지출에 저장된 환율을 사용하며 실시간 환율이나 새 환율을 추가 적용하지 않는다. 원화 통합과 통화별 정산의 차이는 [정산 방식](settlement.md#정산-방식)을 따른다.
