## 수집 항목

서비스는 소셜 로그인으로 회원을 식별하는 데 필요한 정보만 저장한다.
가입할 때 받는 동의와 선택 정보는 [유저 정책서의 회원가입](user.md#회원가입)을 따른다.

다음 표는 소셜 로그인으로 받는 정보의 저장 여부다.

| 항목 | 저장 여부 | 이유 |
| --- | --- | --- |
| 소셜 제공자와 제공자 내부 계정 ID | 저장함 | 같은 계정을 식별함 |
| 소셜 표시 이름(Google `name`, Kakao `nickname`, Apple `fullName`) | 저장하지 않음 | 서비스가 임의 닉네임을 부여해 쓰는 곳이 없음 |
| 이메일 | 저장하지 않음 | ID 토큰에 있어도 읽지 않음 |
| 소셜 프로필 사진 | 저장하지 않음 | 소셜 제공값을 쓰지 않음 |
| 출생연도와 나이 | 저장하지 않음 | 만 18세 이상 여부만 확인함 |
| Apple Refresh Token | 암호화해 저장함 | 회원 탈퇴 때 Apple 연결을 해제함 |

서비스는 가입할 때 만 18세 이상인지에 대한 회원의 확인만 받고, 그 확인 결과도 저장하지 않는다.
서비스는 로그인과 토큰 갱신 때 접속 기록으로 IP 주소를 저장한다([로그와 접속 기록](#로그와-접속-기록)).
서비스는 영수증 원본 이미지를 저장하지 않는다([이미지 처리와 결제 정보](expense.md#이미지-처리와-결제-정보)).

## 저장 위치와 보관 기간

서비스는 회원 데이터, 백업과 로그를 모두 국내 클라우드 리전(Oracle Cloud Infrastructure 춘천 리전)에 저장한다.

다음 표는 데이터별 보관 기간이다.

| 데이터 | 보관 기간 |
| --- | --- |
| 회원, 여행, 지출과 로그인 세션 | 회원 탈퇴 정책을 따름 |
| 운영 DB 백업 | 7일 |
| 서버 로그 | 7일 |
| 로그인 기록(회원 ID, 일시, IP 주소) | 3개월 |
| 영수증 원본 이미지 | 저장하지 않음 |

회원 탈퇴 때 삭제와 보존은 [유저 정책서의 회원 탈퇴](user.md#회원-탈퇴)를 따른다.
서버의 저장 구성과 백업 실행 방식은 [운영 환경과 개인정보 보호](../design/operations-privacy.md)에서 관리한다.

## 로그와 접속 기록

서비스는 웹 서버 접근 로그와 애플리케이션 로그를 남긴다.

다음 표는 로그에 남기는 항목과 남기지 않는 항목이다.

| 로그 | 남기는 항목 | 남기지 않는 항목 |
| --- | --- | --- |
| 웹 서버 접근 로그 | 요청 시각, 호스트, 메서드, 경로(쿼리 제외), 응답 코드, 응답 크기, 처리 시간, 요청 ID, User-Agent | IP 주소, 쿼리 문자열, 쿠키, `Authorization` 헤더, 요청 본문 |
| 애플리케이션 로그 | 이벤트 이름, 회원 ID, 세션 ID, 오류 종류 | 토큰, 인가 코드, 비밀값 |

서비스는 로그를 저장하기 전에 토큰과 비밀값 형태의 문자열을 한 번 더 가린다.
보관 기간이 지난 로그는 서비스가 자동으로 지운다.

서비스는 위 로그와 별도로 로그인 기록(회원 ID, 일시, IP 주소)을 3개월 보관한다.
로그인 상태는 로그아웃할 때까지 유지되므로, 서비스는 로그인할 때뿐 아니라 토큰을 갱신할 때도 로그인 기록을 남긴다.
서비스가 IP 주소를 남기는 곳은 로그인 기록뿐이다.
IP 주소를 남기므로 개인정보 처리방침의 자동 수집 항목에 IP 주소를 적는다.

> 논의 필요
>
> - 탈퇴한 회원의 로그인 기록도 3개월 보관할지 여부. 탈퇴 API를 구현할 때 정한다.
> - IP 주소를 읽지 못한 로그인 기록의 처리: IP 주소 없이 저장함 vs 기록을 남길 수 없으면 로그인과 토큰 갱신을 거절함. IP 주소가 없는 기록이 접속지 추적자료 보관 의무를 채우는지는 확인하지 못했다. 지금 동작의 근거는 [#48](https://github.com/JECT-Study/Billit-5th-Docs/pull/48)에 있다.

## 처리 위탁과 국외 이전

서비스는 영수증 인식을 외부 AI에 위탁한다.
영수증 인식의 처리 기준은 [이미지 처리와 결제 정보](expense.md#이미지-처리와-결제-정보)를 따른다.

다음 표는 개인정보 처리를 위탁하는 수탁자다.

| 수탁자 | 위탁 업무 | 이전 국가 | 전달 항목 |
| --- | --- | --- | --- |
| Google LLC (Gemini API) | 영수증 이미지에서 지출 정보 추출 | 미국 | 영수증 이미지 |

[Gemini API 추가 약관](https://ai.google.dev/gemini-api/terms)(2026-03-23 시행)에 따르면 Google은 유료 서비스의 프롬프트와 응답을 정책 위반 감시를 위해 제한된 기간 동안 기록하며, 제품 개선에는 쓰지 않는다.
약관에 구체적인 보관 기간이 없으므로 개인정보 처리방침에도 기간을 적지 않는다.

## 파기

회원이 탈퇴하거나 데이터를 삭제해도 백업에는 7일 동안 남는다.
백업이 실패한 날이 있으면 최근 성공한 백업 7개를 남기므로, 백업이 7일보다 오래 남을 수 있다.
개인정보 처리방침의 파기 조항에 백업 보관 기간 7일과 이 예외를 적는다.
탈퇴 때 즉시 삭제하는 항목과 한시적으로 보존하는 항목은 [유저 정책서의 회원 탈퇴](user.md#회원-탈퇴)를 따른다.

## 보호 조치와 유출 통지

앱과 서버는 HTTPS(TLS 1.2, 1.3)로 통신한다.
서버 접근 권한과 유출 사고 때의 차단 절차는 [운영 환경과 개인정보 보호](../design/operations-privacy.md)에서 관리한다.

서비스는 이메일을 저장하지 않으므로 유출 사고가 나도 이메일로 회원에게 개별 통지할 수 없다.
1차 MVP에서 서비스는 유출 사고를 앱 공지로 알린다.

> 추후 검토
>
> 유출 통지를 위한 이메일 저장은 배포 뒤 필요하면 다시 정한다.
