# 유저 설계서

## 회원 테이블 변경

| 대상 | 기존 검토 DDL | 변경 방향 | 확정 범위 |
| --- | --- | --- | --- |
| `member.nickname` | `UNIQUE (nickname)` | UNIQUE 제약 제거 | 계정 닉네임 중복 허용 확정. 여행방에서는 [여행방 닉네임](../policy/trip.md#여행방-닉네임)을 사용한다. |
| `member.name`, `member.age` | `name VARCHAR(50)`, `age INTEGER`, NULL이면 미입력 | 두 컬럼 삭제 | 가입할 때 이름과 나이를 입력받지 않아 사용하지 않는다([선택 정보](../policy/user.md#선택-정보)). |

## Apple 연결 해제

Apple 로그인 회원이 탈퇴하면 저장한 Apple Refresh Token으로 Apple 토큰 해지 API(`/auth/revoke`)를 호출한다. 해지 호출은 [서버 PR #33](https://github.com/JECT-Study/Billit-5th-Server/pull/33)에 구현했고, 탈퇴 API를 구현할 때 연결한다. 해지가 성공한 경우에만 저장한 토큰을 지운다. 해지 실패와 복호화 불가의 처리는 [인증 세션과 토큰](authentication.md#apple-연결-해제-토큰)을 따른다.

## 탈퇴 때 삭제와 보존

탈퇴 처리는 탈퇴 API를 구현할 때 다음 기준으로 만든다. 업무 기준은 [유저 정책](../policy/user.md#회원-탈퇴)을 따른다.

| 대상 | 처리 |
| --- | --- |
| 소셜 식별값, 계정 닉네임, 선택 정보 | 탈퇴 즉시 지운다 |
| 여행방 닉네임(`trip_member.trip_nickname`) | 탈퇴 즉시 지운다. 공동 기록에는 참여자 상태 `WITHDRAWN`을 보고 '탈퇴한 사용자 N'으로 표시한다 |
| 회원 행 | 지우지 않고 탈퇴 상태로 바꾼다 |
| Apple 토큰 | Apple 로그인 회원이면 탈퇴 즉시 해지한다([Apple 연결 해제](#apple-연결-해제)) |
| 송금 관계와 금액 | 계정과 연결을 끊은 별도 기록으로 남긴다 |
| 탈퇴 사유 | 회원 ID 없이 `withdrawal_reason` 테이블에 따로 저장한다 |

별도 기록은 정산이 완료되었거나 탈퇴일로부터 90일이 지나면 서버 스케줄러가 매일 지운다. 90일은 회사 정책안이며 법적 근거는 [유저 정책](../policy/user.md#공동-기록과-미완료-정산)의 논의 필요를 따른다.

로그인 참여자의 여행방 닉네임도 `trip_nickname`에 저장한다([여행 테이블 변경](trip.md#여행-테이블-변경)).
탈퇴할 때는 값을 다른 문구로 바꾸지 않고 비운다.
`UNIQUE (trip_id, trip_nickname)`은 NULL끼리 중복으로 보지 않으므로 같은 여행방에서 여러 명이 탈퇴해도 충돌하지 않는다.

유저 정책은 프로필 이미지와 개인 리시트도 탈퇴 즉시 삭제한다고 정한다. 두 항목은 지금 따로 저장하지 않아 위 표에 넣지 않았다.

- 프로필 이미지는 저장 컬럼과 스토리지 경로가 아직 없다. 저장 방식을 정할 때 탈퇴 즉시 Object Storage에서 지우는 처리를 함께 정하고 위 표에 추가한다.
- 개인 리시트는 따로 저장하지 않고 정산과 송금 데이터로 조회할 때마다 만든다. 계정과 연결을 끊으면 탈퇴자 본인은 볼 수 없고, 다른 참여자에게는 [공동 기록 표시 기준](../policy/user.md#공동-기록과-미완료-정산)에 따라 노출하지 않는다. 리시트를 이미지 등으로 저장하게 되면 위 표에 추가한다.
