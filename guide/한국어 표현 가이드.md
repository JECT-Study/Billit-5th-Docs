# 한국어 표현 가이드

## 목적과 적용 범위

이 가이드는 Billit 문서에서 의미가 분명하고 자연스러운 한국어를 쓰기 위한 기준이다. 내용의 근거, 확정 여부와 문단의 전개는 [공통 문서 작성 가이드](<공통 문서 작성 가이드.md>)를 따른다.

한국어 설명문에 적용하며 코드, 코드 주석, 변수명, 로그 문자열과 커밋 메시지의 관례를 바꾸는 기준으로 사용하지 않는다. 인용문과 실제 화면 문구는 원문을 유지한다. 외국어 표기나 원문 유지가 필요한 내용은 임의로 번역하지 않는다.

## 주체와 대상이 분명한 문장

- 사용자 행동은 사용자를, 시스템 동작은 시스템을 주체로 쓴다. 주체가 명확하면 매 문장에 반복하지 않는다.
- 뜻을 이해하는 데 필요한 주어, 목적어와 맥락을 생략하지 않는다. 짧게 쓰더라도 누가 무엇을 하고 어떤 결과가 생기는지 알 수 있어야 한다.
- 수식어가 어느 대상에 붙는지 분명하게 쓴다. 여러 조건이 겹쳐 의미가 흐려지면 조건과 동작을 나누어 설명한다.
- 주체가 중요한 동작을 피동형으로만 설명하지 않는다. 다만 행위자보다 결과가 중요하면 자연스러운 피동 표현을 사용할 수 있다.

## 완결된 문장과 자연스러운 연결

- 본문은 서술어와 종결어미를 갖춘 문장으로 쓴다. 제목과 표의 짧은 항목을 제외하면 `처리 가능`, `영향 없음` 같은 명사구나 연결어미로 끝내지 않는다.
- 조사와 어미를 과도하게 생략하지 않는다. 문장 성분 사이의 관계가 드러나도록 쓴다.
- 조건과 결과, 원인과 영향을 연결할 때는 관계를 명시한다. 접속사를 붙이는 것만으로 논리적 연결을 대신하지 않는다.
- 모든 문장을 같은 길이나 구조로 맞추지 않는다. 함께 읽어야 의미가 분명한 내용은 연결하고, 독립된 판단은 나눈다.

## 행동과 상황을 설명하는 표현

`책임 분리`, `기준 정리`, `흐름 개선`, `일관성 확보` 같은 추상적인 표현만으로 설명을 끝내지 않는다. 무엇을 나누고 어떤 기준을 적용하며 무엇이 달라지는지 필요한 만큼 설명한다.

`정상 처리`, `적절히`, `필요시`, `유연하게`, `관련 내용`처럼 조건이나 결과를 알 수 없는 표현은 근거를 확인해 구체화한다. 원문에 없는 조건이나 효과를 덧붙여 구체적으로 보이게 만들지는 않는다.

명사에 여러 관계를 압축하기보다 행동과 상황을 문장으로 푼다. 이미 뜻이 명확한 명사, 정확한 기술 용어와 제목까지 억지로 풀어 쓰거나 설명을 불필요하게 늘리지는 않는다.

아래 예시는 표현을 비교하기 위한 것이며 새로운 정책을 정의하지 않는다.

| 피하는 표현 | 권장 표현 |
| --- | --- |
| 개인 환율 변경에 따른 기존 지출 영향 없음. | 개인 환율을 변경해도 기존 지출의 환율은 바뀌지 않는다. |
| 멱등성 보장을 통한 중복 저장 방지. | 서버는 같은 고유키의 재요청으로 지출을 다시 저장하지 않는다. |
| 응답 수신 실패 시 재시도 수행. | 앱이 응답을 받지 못하면 같은 고유키로 저장을 재시도한다. |

## 번역투와 과장된 표현

- 자연스러운 한국어 표현이 있으면 불필요한 영어 표현을 사용하지 않는다. 고유명사와 기술 용어는 널리 쓰이고 의미가 정확한 한국어 표현이 있을 때만 바꾼다.
- 한자어나 추상적인 명사를 겹쳐 뜻을 압축하지 않는다. 문장을 읽었을 때 실제 동작이나 상태를 이해할 수 있는지 확인한다.
- 낯선 비유나 과장된 은유로 일반적인 동작을 설명하지 않는다. 중요성과 효과는 확인한 근거의 범위에서 쓴다.
- 대화의 축약어와 말투를 문서에 그대로 옮기지 않는다. 문서의 목적에 맞는 정돈된 설명으로 바꾼다.

## 문장부호

- 항목을 나열할 때는 쉼표, 접속사나 줄바꿈을 사용한다. 가운데점으로 여러 개념을 연결하지 않는다.
- 엠대시로 원인, 결과나 부연 설명을 압축하지 않는다. 관계에 맞는 접속사, 콜론이나 별도 문장으로 풀어 쓴다.
- 인용문과 코드 식별자에 포함된 문장부호는 문체를 맞추기 위해 바꾸지 않는다.

## 표현 검토

초안을 쓴 뒤에는 문장이 문법적으로 맞는지만 보지 않고, 독자가 실제 의미를 이해할 수 있는지 확인한다.

- 주체와 대상, 수식어의 관계가 분명한가?
- 조사와 어미를 생략해 메모처럼 읽히는 문장이 없는가?
- 추상적인 명사 나열을 실제 행동과 결과로 설명했는가?
- 원인과 결과의 관계가 분명하며, 근거 없는 영향을 덧붙이지 않았는가?
- 불필요한 영어 표현, 번역투나 과장된 비유가 없는가?
- 자연스럽게 고치는 과정에서 조건, 의무 수준과 확정 여부가 달라지지 않았는가?
