# Billit-docs

## 소개

Billit 서비스의 문서 저장소입니다. 서비스 정책, API 스펙과 구현 설계를 Git으로 관리합니다.

문서 작성과 변경 방법은 [문서 기여 규칙](CONTRIBUTING.md)을 따릅니다.

화면 구성과 사용자 흐름은 Figma를 참조합니다. API Markdown은 검토와 설명을 위한 문서이며, 실행 가능한 API 계약의 원본은 백엔드 OpenAPI에서 관리합니다.
